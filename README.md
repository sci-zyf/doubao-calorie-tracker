# calorie-tracker

> **豆包专用 Skill** — 本技能专为豆包（Doubao）Agent 模式设计，依赖豆包的 Skill 加载机制、飞书多维表格（lark-cli）和对话内 ECharts 渲染能力，不可在其他环境独立运行。

饮食热量与身体档案记录助手。识别食物图片或文字，估算热量和三大营养素（碳水、蛋白质、脂肪），经用户确认后写入飞书多维表格，自动按日汇总，并支持查询累计摄入、修改目标、记录运动消耗、记录体重围度、输出历史趋势图表。

## 安装与使用

### 方式一：让豆包自动安装（推荐）

本 Skill 为豆包专用，无需手动下载。复制下方提示词，**打开豆包的工作模式**，粘贴并发送即可：

```
请帮我安装 calorie-tracker 豆包 Skill。

仓库地址：https://github.com/sci-zyf/doubao-calorie-tracker

请执行以下操作：
1. 先确认当前环境的用户技能目录路径：从系统提示的 installed-skills 中找到 S2（用户技能目录）对应的实际路径；若无法获取，默认使用 ~/.doubao/agent_mode/workspace/.user_skills/
2. 在该路径下创建 calorie-tracker/ 目录及 references/ 子目录
3. 从仓库拉取以下文件到对应位置：
   - SKILL.md → calorie-tracker/SKILL.md
   - README.md → calorie-tracker/README.md
   - references/charts.md → calorie-tracker/references/charts.md
   - references/table-template.md → calorie-tracker/references/table-template.md
4. 从 GitHub 获取最新版本号：请求 https://api.github.com/repos/sci-zyf/doubao-calorie-tracker/releases/latest，取返回的 tag_name（去掉前缀 v，如 v1.0.0 → 1.0.0）；若无 release 则请求 https://api.github.com/repos/sci-zyf/doubao-calorie-tracker/tags 取第一个
5. 检查 config.json 是否已存在：
   - 不存在 → 创建 config.json，写入 {"initialized": false, "version": "获取到的版本号", "tables": {}, "profile": {}}
   - 已存在 → 只更新 version 字段为最新版本号，**绝对不要覆盖 tables 和 profile**（含飞书访问令牌和个人数据）
6. 安装完成后告诉我当前版本号，并列出已创建的文件，并提示我启动新会话（工作模式）以使用技能。
```

> 提示词会让 AI 自动判断当前是豆包云电脑还是本地电脑，选择对应的 user_skills 路径，无需手动区分。

安装完成后**打开新的豆包会话（工作模式）**，新技能会被自动加载。首次使用时发送食物图片或说"记录早餐"，技能会自动引导创建专属飞书多维表格并填写个人参数（含基础代谢和每日目标，必填）。

### 方式二：手动安装（高级用户）

先确认你的豆包用户技能目录路径（云电脑和本地电脑路径可能不同），然后将本仓库放入该目录：

```bash
# 以实际 user_skills 路径为准，以下为云电脑默认路径示例
git clone https://github.com/sci-zyf/doubao-calorie-tracker.git \
  ~/.doubao/agent_mode/workspace/.user_skills/calorie-tracker
```

或下载 ZIP 解压后，将 `calorie-tracker` 文件夹放入你的 user_skills 目录。

### 使用示例

- "这餐多少卡" + 食物图片 → 估算并记录
- "今天吃了多少" → 当日摄入汇总 + 三图
- "本周统计" → 区间查询
- "看历史 / 近一个月趋势" → 内嵌 ECharts 趋势图（默认）
- "生成HTML看板" → 交互式 HTML 看板（可下载，支持切换时间范围）
- "今天跑步消耗300卡" → 记录活动能量
- "今天体重70" → 记录身体档案
- "把每日预期摄入改成1800" → 修改目标

本 Skill 发布更新后，按以下方式同步最新版本：

**方式一：对话内直接更新（推荐）**

复制下方提示词，粘贴到豆包对话中发送即可：

```

请执行以下操作：
1. 先确认当前环境的用户技能目录路径，找到已安装的 calorie-tracker/ 目录

   - SKILL.md
   - README.md
   - references/charts.md
   - references/table-template.md
3. 从 GitHub 获取最新版本号：请求 https://api.github.com/repos/sci-zyf/doubao-calorie-tracker/releases/latest，取返回的 tag_name（去掉前缀 v）；若无 release 则请求 https://api.github.com/repos/sci-zyf/doubao-calorie-tracker/tags 取第一个
4. 更新 config.json 中的 version 字段为最新版本号（绝对不要删除或覆盖 config.json 中的其他字段，含飞书访问令牌和个人数据）
```

**方式二：git clone 安装的用户**

在 skill 目录下执行 `git pull` 即可。

**方式三：重新发送安装提示词**

重新发送一次安装提示词，AI 会从 GitHub 拉取最新文件覆盖，并检测到 config.json 已存在，只更新 version 字段，不覆盖 tables 和 profile（你的表格配置和个人数据保留）。

更新后需**重启豆包会话**使新版本生效。

### 如何卸载

在豆包电脑端或网页端，进入左侧导航栏的 **「技能·连接器·伙伴」**，找到 **「个人技能」** 栏目，找到 `calorie-tracker` 并删除即可。

> 删除技能仅移除本地技能文件，你在飞书多维表格中的饮食记录、身体档案等数据不会被删除。如需彻底清除数据，需手动删除对应的飞书多维表格。

## 功能介绍

| 功能 | 说明 |
|---|---|
| 饮食记录 | 发送食物图片或文字描述，自动估算热量+三大营养素，确认后写入飞书多维表格 |
| 每日汇总 | 自动按日期聚合早餐/午餐/晚餐/加餐的热量与营养素，计算摄入余量、基础代谢缺口、真实热量缺口、营养素占比 |
| 活动能量 | 记录每次运动消耗（如跑步、健身），独立明细表，支持一天多次累加，自动计入真实热量缺口 |
| 查询统计 | 支持当日查询、区间查询（本周/昨日/自定义）、明细查询（某餐吃了什么） |
| 历史趋势 | 默认输出内嵌 ECharts 图表，可切换生成交互式 HTML 看板 |
| 身体档案 | 记录体重、胸围、腰围、臀围、大腿围、手臂围、小腿围，自动计算 BMI 和分类 |
| 目标配置 | 可修改每日预期摄入、基础代谢、身高、出生日期、性别等个人参数 |

## 支持的图表（共 7 种）

**当日三图（默认输出，内嵌 ECharts，对话内直接展示）：**

1. 各餐热量分布（圆环图）
2. 三大营养素（圆环图）
3. 热量缺口（柱状图 + 虚线参考线：基础代谢 / 已摄入 / 基础代谢缺口 / 真实热量缺口，每日预期摄入以灰色虚线展示）

**历史趋势（两种输出模式）：**

- **默认模式**：内嵌 ECharts，对话内直接展示两张图
  4. 热量趋势（三线折线：总热量 / 每日预期摄入 / 基础代谢）
  5. 营养素趋势（双轴：100% 堆叠柱占比 + 总质量折线）
- **HTML 看板模式**（用户明确要求时生成，可下载）：在默认两张图基础上增加身体档案图，支持粒度（日/周/月/年）和范围（本周/近30天/近90天/自定义）切换、多图联动刷新
  6. 体重 + BMI（双轴折线）
  7. 六项围度（多折线，支持图例显隐）

> 历史趋势查询时，默认给出内嵌 ECharts 并提示"可生成 HTML 看板实现更复杂的交互分析"，但不主动生成 HTML；用户回复"生成HTML看板"后才输出可下载的 HTML 文件。

## 热量缺口统计逻辑

本 Skill 区分两个热量缺口，含义不同：

| 指标 | 公式 | 说明 |
|---|---|---|
| **基础代谢缺口** | 基础代谢 - 总热量摄入 | 不含运动，反映"躺着不动"的热量差；为正表示有缺口，为负表示摄入已超基础代谢 |
| **真实热量缺口** | 基础代谢 + 活动能量 - 总热量摄入 | 含当天运动消耗，反映实际热量差；**减脂期主要看这个** |
| **摄入余量** | 每日预期摄入 - 总热量摄入 | 今天还能吃多少，为正表示未超目标，为负表示已超标 |

- 活动能量由「活动记录」表按日期自动聚合，每次运动单独一条记录，支持一天多次累加；录入时会先列出当天已有活动明细，避免重复记录
- 基础代谢和每日预期摄入在初始化时由用户填写（附男女参考值），后续可单独修改
- 所有指标由多维表格公式自动计算，写入饮食记录或活动能量后无需手动更新

## 数据存储

所有数据写入用户自己的飞书多维表格（Base），包含四张表：

- **饮食记录**：每餐一条，食物描述、日期、餐次、热量、三大营养素、备注
- **每日汇总**：每天一条，基础代谢、每日预期摄入，其余由公式自动聚合（总热量、摄入余量、基础代谢缺口、真实热量缺口、活动能量、营养素占比等）
- **身体档案**：每次测量一条，体重、六围度，BMI 由公式自动计算
- **活动记录**：每次运动一条，运动项目、日期、消耗热量、备注；活动能量由每日汇总表按日期自动聚合

首次使用时自动引导创建专属表格，数据只写入用户自己的表格。

## 目录结构

```
calorie-tracker/
├── SKILL.md                  # 主入口：工作流定义、查询/记录/历史趋势路由
├── README.md                 # 本文件
├── .gitignore                # 忽略 config.json 和 .DS_Store
├── config.json               # 运行时配置（base_token、table_id、用户profile，首次使用自动生成，不纳入版本库）
└── references/
    ├── charts.md             # 图表规范：颜色、布局约束、当日三图模板、历史看板规范
    └── table-template.md     # 表结构模板：四张表的字段定义
```

## 注意事项

- `config.json` 包含飞书表格的访问令牌（base_token），属于敏感信息，**请勿提交到公开仓库**，已加入 `.gitignore`
- 热量估算基于图片视觉分量，仅供日常参考，允许误差
- 所有写入操作需经用户确认，不会自动写入
- 本 Skill 依赖豆包 Agent 模式的 Skill 加载机制和 `lark-cli` 飞书命令行工具，脱离豆包环境无法运行
- **版本号**：安装/更新时自动从 GitHub 获取最新 Release tag（如 `v1.0.0`），去掉前缀 `v` 后写入 `config.json` 的 `version` 字段。每次 `git push` 新版本 tag 后，用户通过更新提示词即可同步到最新版本号
